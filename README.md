# Smart Search FS Bogor — Aplikasi Pencarian Homepass & Splitter ID

Aplikasi Streamlit untuk pencarian data Homepass dan Splitter ID - Fiberstar Bogor.

## Cara Menggunakan

Ketik nama jalan, blok, nomor rumah, Homepass ID, atau Splitter ID di kolom pencarian.

## Teknologi

- Python + Streamlit
- Pandas
- openpyxl
